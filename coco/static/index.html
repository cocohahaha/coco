和 coco 对话
你好，我是 coco。选中左侧会议后，可以问我任何关于这场对话的问题：决策、情绪、行动项、隐藏的分歧……勾选「跨全部会议」还能问跨场次的问题。开会前记得用「◎ 会前」让我先帮你看懂局。

记忆（注入每一次 AI 分析）

校正以词表与记忆里的写法为准，统一修正所有会议的转写与报告（耗时数分钟）

导出 .md

勾选要导出的文件，打包成一个 zip 下载。也可直接在左侧会议列表勾选后点「下载选中」。

导入材料

粘贴文件或文件夹的完整路径。音频/视频会转写；txt / md / srt / vtt / json 等文字材料直接入库。 指向文件夹则批量导入其中全部可识别文件。Finder 选中后按 Option+Cmd+C 可拷贝路径。
把聊天记录、邮件、他人会议纪要等文字材料直接粘进来，coco 会像对待转写一样分析它，并并入长期记忆。

◎ 会前调查

先看懂局，再进会。coco 会自动挑出与主题/参会人最相关的历史会议，结合长期记忆与词表， 生成关键人立场、阻力与机会、建议打法和问题清单。

⛓ 跨会议洞察

跨多场会议交叉分析。会议较多时需要数分钟。
