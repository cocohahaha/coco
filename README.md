# coco — 本地会议参谋：录音 / 转写 / 分析 / 会前调查 / 知识沉淀

[YouNavi](https://younavi.me) 的本地复刻与扩展：录音与已有材料入库、本地 Whisper 转写、
会前调查、跨会议洞察（追踪 / 深层信号 / 调研综合）、每日简报、长期记忆与词表沉淀。
全部数据留在本机，AI 分析通过本机 `claude` CLI 完成（无需额外 API key）。

典型场景：FDE / 顾问进入一家新公司，把多方访谈、历史会议、聊天记录都喂进来，
用「调研综合」交叉对比各方诉求与痛点，用「会前调查」在每场关键会议前看懂局，
用「知识底座」沉淀人物、项目、承诺与术语。

## 快速开始

**最快方式：在 Finder 里双击 `coco.command`**（或终端运行 `./run.sh`）——
自动启动服务并打开浏览器，重复运行不会重复起服务。

```bash
cd "~/Documents/Tool Creation/录音"

./run.sh                           # 一键启动网页版 → http://127.0.0.1:8765
./bin/coco transcribe 某录音.m4a    # 命令行导入音频/视频并转写
```

材料入库四种方式：**拖拽进窗口**（音频/视频/文字都行）、「↑ 上传」多选、
「⌖ 导入」粘贴本地路径（文件夹=批量），以及「⌖ 导入 → 粘贴文本」直接贴聊天记录、
邮件、他人纪要等文字材料——**归集私人上下文**，文字材料不转写直接入库，
之后的报告、对话、简报、洞察、长期记忆全部照常工作。
支持的文字格式：txt / md / srt / vtt / json（Whisper 风格）。

核心能力：

- **◎ 会前调查**：填主题、参会人、目标，coco 自动挑出最相关的历史会议，
  结合长期记忆与词表生成会前简报——局势判断、关键人立场与历史表态、
  阻力与机会、建议打法与问题清单；可勾选联网搜索公开信息（结果注明来源）。
  历史简报存 `library/_prep/`，界面可翻看
- **⛓ 洞察（跨会议）**：三种模式——
  「追踪」承诺履行 / 表态变化 / 未决问题；
  「深层信号」非共识 / 潜台词 / 立场与利益 / 观点漂移 / 盲区；
  「调研综合」多方访谈交叉对比：痛点矩阵、共识与分歧、信息盲区、落地方向建议（FDE 调研场景）。
  范围可选全部会议或左侧勾选的几场，可聚焦某个人/项目
- **☷ 知识底座**：人物 / 项目 / 承诺 / 词表的沉淀总览，统计一目了然；
  点任意人物即可跨全部会议梳理 TA 的表态变化与未兑现承诺
- **词表（人名+专有名词）**：`memory/glossary.md`，格式
  `- 正确写法（误写：错1、错2）｜备注`。正确写法自动注入转写提示
  （受 whisper 防复读机制所限，提示主要作用于音频开头——好在人名多在开场出现；
  全文的同音字纠错靠下面的「校正」完成）；全表是校正与分析的依据。
  「◈ 记忆 → 词表」可编辑，「✦ 提炼词表」让 AI 从长期记忆与最近转写中自动归集
- **✦ 人名与术语校正**：按词表统一修正全部会议转写与报告中的人名和专有名词
  （原文自动备份，可逐场「↺ 恢复原稿」）
- **长期记忆（自动）**：每场转写/导入完成后，自动提取人物、项目与客户、
  承诺与决定、术语，合并进 `memory/longterm.md` 并注入之后所有分析；
  每日简报生成后也自动并入。任何覆盖/清空前都自动备份 .bak.md；
  不想要可 `coco config auto_memory false`
- **每日简报（含历史）**：日期下拉翻看历史，未生成的日期一键补生成
- **✎ 编辑 / 模型切换 / 全局搜索 / 回收站删除 / 跨全部会议提问**：同前，
  新增「跟进草稿」报告模板——会后直接生成可发送的跟进消息 + 48 小时行动清单

建议把 CLI 加入 PATH：
```bash
echo 'alias coco="~/Documents/Tool\ Creation/录音/bin/coco"' >> ~/.zshrc
```

## 全部命令

| 命令 | 作用 |
|---|---|
| `coco transcribe <文件…>` | 导入音频/视频转写（`--model turbo` 换快速模型） |
| `coco import <文件/文件夹…>` | 导入已有文字材料（txt/md/srt/vtt/json），不转写直接入库 |
| `coco list` / `coco show <会议>` | 查看会议库 / 某条转写 |
| `coco ask "问题" [会议…]` | 对会议内容提问（默认最近一条，可引用多条） |
| `coco report <会议> -t 模板` | 生成分析报告（`coco templates` 看全部模板） |
| `coco prep "主题" [--who 人] [--goal 目标] [--web]` | 会前调查：生成会前简报（--web 联网查公开信息） |
| `coco brief [日期]` | 每日简报：汇总当天所有会议的行动项与洞察 |
| `coco track [焦点] [--mode 深层信号\|调研综合] [--refs 会议…]` | 跨会议洞察（默认追踪模式） |
| `coco search <词>` | 全文搜索所有转写和报告 |
| `coco delete <会议>` | 删除会议（移入回收站 `library/_trash`） |
| `coco memory [内容]` | 查看/追加全局记忆（公司背景、偏好，注入每次分析） |
| `coco glossary [词条] [--extract]` | 查看/追加/AI 提炼词表（人名与专有名词） |
| `coco memorize [会议\|--all]` | 手动触发长期记忆提取（转写后默认自动做） |
| `coco watch <文件夹>` | 监控文件夹，新音频自动转写（适合接语音备忘录、Plaud 导出目录等） |
| `coco record [标题]` | （可选）麦克风录音，Ctrl+C 停止后自动转写 |
| `coco web` | 启动本地 Web 界面（全部能力都有 UI 入口） |
| `coco config [键 值]` | 查看/修改配置 |

## 分析模板

纪要 · 行动项 · 情绪曲线 · 张力与分歧 · 认知偏误 · 话题延伸 · 客户跟进 · 招聘评估 · 跟进草稿
（在 `coco/templates.py` 里可自行增改；跨会议洞察的三种模式也在同一文件）

## 配置说明（coco config）

- `whisper_model`：`turbo`（默认）或 `large`，网页顶栏也可切换。
  本机实测（M 系列，5 分钟真实会议音频）：turbo 约 23 倍速、large 约 7 倍速，
  即 45 分钟会议 turbo 约 2 分钟、large 约 6-7 分钟。
- `initial_prompt_extra`：常出现的人名/品牌/术语（逗号分隔），注入转写提示提高识别准确率。
- `auto_memory`：转写完成后是否自动提取长期记忆（默认 true）。
- `claude_extra_args`：传给 claude CLI 的额外参数，如 `["--model","claude-sonnet-4-6"]`。
- `hf_endpoint`：模型下载源；网络不通时自动切换到 hf-mirror.com。

## 数据位置（全部本地）

```
library/<日期-标题>/   音频 audio.wav（或文字材料 source.*）+ transcript.md/json + reports/*.md
library/_briefs/       每日简报
library/_tracking/     跨会议洞察报告（追踪/深层信号/调研综合）
library/_prep/         会前调查简报
library/_trash/        回收站（删除的会议，可手动恢复）
memory/memory.md       全局记忆（手动维护）
memory/longterm.md     长期记忆（自动提取，可手动修订）
memory/glossary.md     词表：人名与专有名词标准写法（可手动/AI 提炼维护）
memory/*.bak.md        记忆与词表的单槽备份（覆盖/清空前自动生成）
coco.config.json       配置（首次 coco config 修改后生成）
```

环境变量 `COCO_ROOT` 可把数据根目录指到别处（测试或多套数据隔离）。

## 注意事项

- 首次录音时 macOS 会弹窗请求终端的麦克风权限，需允许。
- 长音频已开启防复读参数（condition_on_previous_text=False），减少 whisper 重复幻觉。
- Web 界面只监听 127.0.0.1，不对外网开放。
